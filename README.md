# GNR Project — MCQ Visual Question Answering

## Directory Structure
Everything is in a single flat directory (no subdirectories):

```
./
├── setup.bash          # Environment setup (run with internet)
├── inference.py        # Main inference script
├── evaluate.py         # Grading script
├── model_weights/      # Downloaded by setup.bash
└── submission.csv      # Generated by inference.py
```

## Setup
```bash
bash setup.bash
conda activate gnr_project_env
```

## Inference
```bash
python inference.py --test_dir <absolute_path_to_test_dir>
```

The test_dir should contain:
- `images/`    — folder with .png images
- `test.csv`   — with columns: id, image_name

Output: `submission.csv` in current directory

## Evaluate
```bash
python evaluate.py --submission_file submission.csv --test_dir <test_dir>
```

## Model
- Qwen3-VL-8B-Thinking (local weights, no internet needed at inference)
- Few-shot prompting with 2 real examples from training data
- Two-pass structured output: free reasoning + LogitsProcessor fallback
